# Cognitive load and programming learning materials

*I wrote my master's thesis on cognitive load and programming learning materials in spring 2023.*

My master's thesis covered topics in cognitive load theory and how its effects could be measured and utilized in programming learning. The complete thesis can be found here (in English). If you're not familiar with cognitive load theory a brief on the theories and main conclusions of the paper can be found here (in Finnish).

## How to manage cognitive load in instructional materials?

I made a summary of design guidelines that are based on cognitive load theory. Creating instructional materials that follow these principles should create a more enjoyable and effective learning experience. Each principle is described below followed by a use case example.

### Multimedia

Use both verbal and visual information, instead of only one of them.

A learning material about spider webs has an animation depicting the process of creating one and text explaining its physical properties.

### Aligned

Place text next to corresponding visualizations.

In a map of Europe, the countries' names are placed within the countries instead of having a list next to the map and connecting the list and map with lines.

### Synchronized

Present mutually dependent materials simultaneously.

A new term is explained with an in-text annotation, e.g. a lead, instead of using footnotes.

### Reduced

Remove redundant or duplicated information regardless of their presentation.

Learning material with an animation explaining photosynthesis does not explain the process again in the text.

### Segmented

Provide the material in a way that allows learners to pace their learning sessions as they wish.

An animation showing the stroke order of a Chinese character can be paused at any point.

### Pretrained

Teach essential elements of the learning platform and key terms of the topic before beginning actual learning.

Before the first lesson, students can complete a tutorial on how code is run on a programming learning website.

### Personalized

Ensure learners have learning materials suitable for their prior knowledge and abilities.

A driving school online learning material is adapted based on the student's previous license.

### Guided

Guide learners to use schema acquisition tools and induce cognitive processes.

Students have to analyze their performance before revealing correct answers or giving feedback.

### Focused

Weed out seductive details and signal important information.

Learning material about felines has all species with bold text and excludes a funny gif of Garfield.

### Narrated

Use narration instead of written text with visualizations.

Video about how lightning is produced is explained simultaneously with narration instead of subtitles.

### Humanized

Make on-screen agents, narrations, and texts human-like.

A video about AI is narrated with a human voice and uses casual language.
