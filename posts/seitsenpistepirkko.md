# Word game with React

*Created a Finnish version of the NYT Bee word game with React. Playable but still a work in progress.*

I had fun creating the concept and theming for my version. The actual gameplay needed multiple reiterations to work well, but this has been this summer's fun little project. I especially enjoyed working with React and coding the user interface.

Try it out here <https://ellamac.github.io/seitsenpistepirkko> (designed for mobiles first and only in Finnish) or check out on [Github](https://github.com/ellamac/seitsenpistepirkko).
