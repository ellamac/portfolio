# Portfolio Website

A personal portfolio website built with React, dynamically rendering project content from Markdown files. The site is deployed on GitHub Pages and leverages React Router DOM for client-side navigation.

## Features

- Dynamic project pages from Markdown files (.md) for easy content updates
- Card navigation for project overview with images and descriptions
- React Router DOM for seamless page transitions
- Markdown rendering using react-markdown
- Fully responsive design for desktop and mobile
- Hosted on GitHub Pages

## Tech Stack

React – Frontend framework

React Router DOM – Client-side routing

MUI Icons – UI icons

React Markdown – Markdown rendering

GitHub Pages – Deployment

JavaScript / CSS / HTML – Core web technologies
